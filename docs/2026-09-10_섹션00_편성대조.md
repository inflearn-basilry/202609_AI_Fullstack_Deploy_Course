# 섹션 00 편성 대조

확인일: 2026-09-10

대조 대상은 자료실의 섹션 00 목록과 실제 슬라이드, 최신 전체 커리큘럼 v0.4입니다. 기존 슬라이드는 v0.2 편성으로 제작됐습니다. 이번 확인에서는 번호나 본문을 재편집하지 않았습니다.

## 확인 결과

| 번호 | 현재 자료실·슬라이드 | 최신 v0.4 | 차이와 필요한 작업 |

| 0-0 | 오리엔테이션 — 강사 소개와 함께 만들 결과 · 12장 · 10분 | 강사 소개와 이 강의를 만든 이유 · 6분 | 소개의 주제는 겹치지만 4분 축약과 초점 조정 필요 |

분량은 계획된 설명·시연 시간이며 실제 녹화물의 재생 시간을 측정한 값이 아닙니다.

## 불일치가 생긴 이유

전체 커리큘럼이 v0.4로 바뀌면서 환경 설치의 상세 설명을 줄이고 기본 코드 읽기를 추가했습니다. 이미 제작한 섹션 00 슬라이드는 이전 편성을 유지했습니다. 자료실에 버전 차이 안내는 있지만 수업이 자동으로 대응하지는 않습니다.

## 최신 편성으로 맞출 때의 제안

1. 0-0을 6분 구성으로 재편집합니다.
2. 0-1·0-3은 기존 내용을 유지하고 전후 연결을 확인합니다.
3. 0-2는 실제 구현 전까지 목표 화면·합성 예시 표시를 유지합니다. 완성본 시연으로 바꾸려면 실제 앱과 테스트·배포 결과가 필요합니다.
4. 0-4는 9분 구성에 맞춰 비용 상한과 권한 설정 실습을 보완합니다.
5. 기존 0-5의 설치 설명은 준비용 보충 자료로 남기고, 기존 0-6의 환경 진단과 핵심 코드 읽기를 묶어 새 0-5를 작성합니다.
6. 강의 번호를 통합하기 전에 이전 자료 링크와 수강 완료 기록의 보존 방법을 정합니다. 기존 완료 체크를 새 수업 완료로 자동 인정하지 않습니다.

이 제안은 아직 실행하지 않았습니다. 기존 섹션 00의 번호·시간·완료 기록을 임의로 바꾸지 않았습니다.
