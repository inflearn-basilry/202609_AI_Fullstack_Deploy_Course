# AI 풀스택 출시 강의 경쟁 조사 및 가격 전략

- 조사 기준일: 2026-09-08
- 대상 강의: **AI 에이전트로 프로덕션 풀스택 출시하기**
- 상태: 출시 전 가격·포지셔닝 의사결정안
- 주의: 수강생 수, 수강평, 할인가는 수시로 변한다. 실제 강의 등록 직전에 다시 확인한다.

## 1. 결론

이 강의는 일반적인 바이브코딩 입문 강의가 아니라, React·API·Git의 기초가 있는 개발자가 AI 에이전트의 결과를 검증해 실제 서비스로 출시하는 과정으로 포지셔닝한다.

핵심 가격안은 다음과 같다.

| 구분 | 가격 | 할인율 | 운용 목적 |
|---|---:|---:|---|
| 정가 | **132,000원** | - | 전문 개발자 과정이라는 기준 가격 유지 |
| 파일럿 한정가 | 79,200원 | 40% | 기존 구독자·초기 피드백 참여자용 제한 쿠폰 |
| 공식 출시가 | **92,400원** | 30% | 출시 후 약 2주간 첫 구매 장벽 완화 |
| 주력 판매가 | **105,600원** | 20% | 수강평 10개 이상 확보 후 기본 프로모션 가격 |
| 안정화 판매가 | 118,800원 | 10% | 판매와 평점이 안정된 이후의 약한 할인 |

권장 하한가는 **79,200원**이다. 이보다 낮아지면 비개발자 대상 입문 강의와 같은 가격대로 인식되며, 선수 지식이 부족한 수강생 유입으로 Q&A 부담이 커질 수 있다.

## 2. 우리 강의의 기준 상품

가격은 영상 길이만으로 정하지 않고, 수강 후 남는 결과물과 검증 수준을 기준으로 정한다.

| 항목 | 내용 |
|---|---|
| 핵심 대상 | 부트캠프 수료생, 사이드 프로젝트가 미완성인 1~3년차 개발자 |
| 예상 분량 | 약 6시간 40분, 9개 섹션, 41개 수업, 7개 미션 |
| 기술 스택 | TypeScript, Next.js, PostgreSQL, Prisma, Zod, Vitest, Playwright |
| 최종 결과물 | SignalDesk 서비스, Git 저장소, 테스트 리포트, 공개 URL, 운영 런북 |
| 핵심 차별점 | AI가 만든 코드를 생성하는 법보다 검증·거절·복구·출시하는 법 |
| 검증 범위 | 구조화 출력, 실패 상태, 타임아웃, 재시도, fallback, 멱등성, 단위·통합·E2E 테스트 |
| 운영 범위 | 구조화 로그, 실행 이력, 비용 확인, 장애 대응, 롤백, Release Evidence |

강의의 핵심 상품은 “기획부터 배포까지”라는 넓은 범위가 아니다. 다음 세 가지 출시 증거가 상품이다.

1. 잘린 JSON·빈 응답·지연·중복 요청을 일부러 발생시키고 복구한 기록
2. 단위·통합·E2E 테스트를 통과한 리포트
3. 공개 URL·구조화 로그·운영 런북·Release Evidence

## 6. 가격 결정 근거

### 6.1 정가를 99,000원으로 두지 않는 이유

- 할인 시 실제 판매가가 6만~8만 원대로 내려가 입문 강의와 같은 인상을 준다.
- 수강생에게 React·API·Git 선수 지식을 요구하는 전문 과정과 가격 메시지가 어긋난다.
- 기업 교육과 플랫폼 프로모션에서 사용할 할인 여지가 작아진다.

### 6.2 정가를 165,000~198,000원으로 두지 않는 이유

- 해당 가격대 경쟁 강의는 대체로 15~24시간 또는 다수 프로젝트를 제공한다.
- 출시 전에는 강의 자체의 수강생·평점·수강평이라는 판매 증거가 없다.
- AI 도구 구독 비용이 별도로 발생하므로 초기 구매자가 느끼는 총비용이 커진다.

### 6.3 132,000원이 적정한 이유

- 초보자용 도구 강의보다 전문적인 포지션을 유지한다.
- 30% 출시 할인 시 92,400원이 되어 시장의 구매 가능한 중심 가격에 들어간다.
- 후기 확보 후 105,600~118,800원으로 자연스럽게 이동할 수 있다.
- 템플릿·완성 저장소·테스트 리포트·운영 런북을 포함하면 시간보다 결과물로 가격을 설명할 수 있다.

## 7. 출시 가격 운영안

### 단계 1. 파일럿

- 가격: 79,200원 상당의 제한 쿠폰
- 대상: 기존 구독자 또는 사전 신청자 최대 20~30명
- 목적: Windows·macOS 환경 문제, 설명 누락, 실습 실패 지점 수집
- 원칙: 수강평 작성을 할인 조건으로 강제하지 않는다.

### 단계 2. 공식 출시

- 가격: 92,400원
- 기간: 약 14일
- 상세 페이지에서 정가 할인보다 아래 결과물을 우선 노출한다.
  - 실패 주입과 복구 장면
  - 단위·통합·E2E 테스트 리포트
  - 공개 URL·로그·운영 런북

### 단계 3. 주력 판매

- 수강평 10개 이상과 평점 4.7 이상이 안정적으로 확인되면 105,600원을 주력 판매가로 사용한다.
- 플랫폼 행사에서는 20% 내외 할인을 기본으로 한다.
- 40% 할인가는 대형 프로모션이나 제한 쿠폰 이외에는 사용하지 않는다.

### 단계 4. 안정화

- 수강생 100명 이상, 수강평 25개 이상, 평점 4.7 이상을 유지하면 118,800원 판매 비중을 늘린다.
- 추가 가격 인상보다 사례 연구, 수강생 결과물, 강의 업데이트 이력을 축적한다.
