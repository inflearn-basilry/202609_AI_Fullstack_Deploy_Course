# Linen Blue v1 전체 적용

## 적용 범위

- 공개 HTML 13개: 자료실 1개, 강의 7개, 커리큘럼·이동 페이지 4개, 디자인 가이드 1개.
- 0-0~0-6 총 75장. 기존 강의 내용·제목·시간·주소는 보존.
- 배경 #EBE8E0, 본문 #232B36, 강조 #2856C5와 공통 상태 색상.
- 로컬 Pretendard Variable WOFF2 및 SIL OFL 라이선스 포함.
- 강사용 비공개 원본과 기존 배포 목적지는 변경하지 않음.

## 검수 결과

- 기존 3개 검사와 Linen Blue 검사 통과. 공개 경계, 로컬 링크, 글꼴 파일, 색상 대비, 75장 내용 보존 확인.
- 1920×1080 데스크톱에서 75장 모두 슬라이드 경계 밖으로 벗어나는 요소 없음.
- 360×800 모바일에서 75장을 순서대로 열어 가로 넘침 없음 확인.
- 자료실·최신 커리큘럼·디자인 가이드의 모바일 및 데스크톱 화면 확인. 구 커리큘럼도 데스크톱에서 확인.
- 0-1 완료 체크를 새로고침 및 자료실에서 확인한 뒤 검사 전 상태로 원복.
- 키보드 이동 및 0-1 컨트롤 숨김→다시 표시 동작 확인.
- 고정 저장 실패 메시지는 모바일에서 문서 흐름에 배치하도록 보완. 저장 거부·용량 초과는 기존 자동 검사에서 검증하며, 실제 브라우저의 저장 권한을 변경하지는 않음.
- 자동화 미리보기에서 Fullscreen API가 거부되어 안내 문구가 표시되는 것을 확인. 실제 전체화면 진입 성공을 주장하지 않음.

## 유지 관리

공통 토큰은 dist/assets/course-theme.css에서 관리합니다. 슬라이드 데이터의 내용은 이번 디자인 변경에 포함하지 않았습니다. CI는 tests/validate-linen-theme.cjs를 포함한 네 가지 검사 후 dist/만 배포합니다.
