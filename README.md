# AI 에이전트로 프로덕션 풀스택 출시하기

인프런 강의 자료와 학생용 정적 자료실을 관리하는 저장소입니다.

## 학생용 사이트

- GitHub Pages: https://inflearn-basilry.github.io/202609_AI_Fullstack_Deploy_Course/
- `main` 브랜치에 변경사항을 올리면 GitHub Actions가 `dist/`를 자동 배포합니다.

## 구조

- `dist/index.html`: 학생용 자료실 첫 화면
- `dist/materials/`: 강의 슬라이드, 스크립트·스토리보드, 커리큘럼, 디자인 시스템
- `docs/`: 경쟁 조사, 가격 전략 등 강의 기획 의사결정 문서
- `.github/workflows/deploy-pages.yml`: GitHub Pages 자동 배포 설정
- `.openai/hosting.json`: 기존 ChatGPT Sites 배포 설정

## 현재 공개 강의

- 0-1. 이 강의가 해결하는 문제

강의 슬라이드는 방향키로 이동하며 `N` 키로 발표자 노트, `F` 키로 전체화면을 열 수 있습니다.

자료실은 **챕터만 접고 펼치며, 개별 강의는 항상 보이는 행**으로 정리했습니다. 00섹션 0-0~0-6의 제목 오른쪽에 **슬라이드 열기 · 스크립트 · 수강 완료**를 모았습니다. 별도 스크립트 목록은 없으며 기존 `#scripts` 링크는 통합 강의 목록으로 연결됩니다. 좁은 화면에서는 버튼이 제목 아래로 이어집니다. 챕터 제목은 Tab으로 이동한 뒤 Enter 또는 Space로 접고 펼칠 수 있습니다.

각 강의의 **수강 완료** 체크는 브라우저 localStorage에 저장됩니다. 같은 브라우저·출처에서 자료실, 현재 커리큘럼(v0.2), 슬라이드, 스크립트의 상태가 공유됩니다. 새로고침해도 유지되며 직접 해제할 수 있습니다. 로그인·계정별 기록이나 기기 간 동기화는 아닙니다. 저장이 차단된 환경에서는 화면에 안내하고 해당 페이지에서만 유지합니다.

00섹션은 7개 강의·총 75장·목표 편집 분량 56분입니다. 0-2는 목표 화면·합성 예시이며, 0-6의 starter·doctor는 아직 제공되지 않은 실습 계약입니다. 실제 앱 시연과 진단 실행 증거는 녹화 전에 별도로 확보해야 합니다.

- [섹션 00 구성·수강 기록·크롤링 제한 및 검증 범위](docs/2026-09-08_섹션00_자료와_수강기록.md)
- `node tests/validate-orientation.cjs`
- `node tests/validate-section00.cjs`

모든 HTML에 `noindex` 등을 추가하고 `dist/robots.txt`에 전체 크롤링 거부를 선언했습니다. 단, GitHub Pages 프로젝트 경로의 robots.txt는 도메인 루트가 아니므로 크롤링 제어 효력이 없습니다. 현재 배포 방식에서 이를 적용하려면 별도 루트 설정이 필요하며, 강제 접근 차단·소스 비공개 기능은 아닙니다. 자세한 한계는 위 문서를 확인하세요.
